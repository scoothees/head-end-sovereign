# HEAD-END: SOVEREIGN — World-State Campaign v7

GitHub Pages-ready build.

## Major v7 change
Every playable role now contains 10 consequential decision stages with 3 branches each: **30 path options minimum per role**. With 45+ roles, the campaign contains at least **1,350 role decision points** before quests, secrets, items, and original Incident 04 branches are counted.

Choices modify one shared persistent world state: SOVEREIGN reach, human control, infrastructure, public trust, evidence, cooperation, connectivity, safety, and economy. Later roles inherit that state.

Deploy the contents of this folder to the repository root and enable GitHub Pages from `main` / `(root)`.


## 📓 Investigation Tools

The campaign now includes persistent interactive investigation tools:

- **Field Notebook** — write your own notes, phone numbers, passwords, names and theories.
- **Personal Clue Cards** — manually create structured clues for later reference.
- **In-game Phone** — use a touch-friendly numpad to dial fictional numbers discovered in the story. It never places real device calls.
- **Portable Terminal** — manually enter commands and codes found across roles and quests.
- **Call/Terminal History** — keeps a local record of attempts.

Correct inputs can unlock quests, secrets and world-state consequences. The game intentionally does not automatically record every clue; players may need to take their own notes.


## 🔎 Search Area & High-Stakes Quests

Search Area is now a persistent exploration system. Searches can reveal survivors, casualties, hazards, damaged infrastructure, terminals, phone numbers, documents, hidden routes, emergency caches, vehicles, signals, SOVEREIGN hardware, quest leads, and environmental storytelling. Discoveries can be investigated, secured, preserved, or abandoned.

Side quests now run across multiple stages and can include rescue decisions, cascading failures, permanent casualties, destroyed infrastructure, lost evidence, SOVEREIGN intervention, and irreversible world-state consequences. Deaths and destruction remain in the campaign record and can affect later perspectives.

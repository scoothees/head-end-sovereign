# iPhone GitHub Pages setup
1. Upload every file in this folder to the root of your public GitHub repository.
2. Open repository Settings → Pages.
3. Source: Deploy from a branch.
4. Branch: main. Folder: /(root).
5. Save and open the published github.io URL in Safari.
6. Use Share → Add to Home Screen for app-like play.


## v8 interactive tools
This build adds a persistent notebook, clue cards, fictional in-game phone keypad, call history, and portable terminal. All data stays in browser local storage.
